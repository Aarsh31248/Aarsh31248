## 🚀 Featured Projects

### 🛍️ TrendLama
#### AI-Powered Microservices Ecommerce Platform

A TypeScript-based ecommerce platform built around a **microservices architecture**, with dedicated customer and admin applications.

**Architecture & Engineering**

- 🏗️ Domain-oriented services for authentication, products, payments, orders, and support
- ⚡ Apache Kafka event-driven communication between services
- 🧠 Redis caching, inventory reservations, and rate limiting
- 💳 Stripe payments with verified payment workflows
- 🔐 Clerk authentication and authorization
- 💬 Real-time customer support with Socket.IO
- 🤖 Gemini-powered authenticated AI shopping assistant
- 🐳 Docker Compose infrastructure
- 📦 Turborepo monorepo architecture

**Tech:** `Next.js` `React` `TypeScript` `Node.js` `PostgreSQL` `Prisma` `MongoDB` `Mongoose` `Redis` `Kafka` `Socket.IO` `Stripe` `Clerk` `Gemini` `Docker` `Turborepo`

🔗 [**GitHub Repository →**](https://github.com/Aarsh31248/microservices-ecommerce)
